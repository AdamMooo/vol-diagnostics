# Phase 20.5 Plan 02: Bump kaleido PNG export resolution Summary

Added `KALEIDO_SCALE_FACTOR = 2.0` to `engine/config.py` and wired it into `export_png()`'s single `fig.write_image()` call, so every kaleido-rendered PNG attachment (ΔIV surface + price-levels charts) exports at 2x resolution for legible pinch-zoom on phone mail clients, with zero change to on-screen HTML display width or attachment order/count.

## What Was Built

- `engine/config.py`: new `KALEIDO_SCALE_FACTOR: float = 2.0` constant in the "PNG export (kaleido)" section, directly below `KALEIDO_CAMERA_EYE`, with a matching one-line-rationale docstring citing D-06.
- `engine/report/png_export.py`: `export_png()`'s `fig.write_image(str(png_path), format="png")` call now passes `scale=config.KALEIDO_SCALE_FACTOR`. No try/except added — module's "callers own failure handling" contract preserved.
- `engine/tests/test_png_export.py`: new `test_export_png_applies_scale_factor` asserting `write_image` was called with the scale kwarg, mirroring the existing `test_export_png_pins_camera` pattern.
