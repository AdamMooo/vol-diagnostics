<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local → cdn.cboe.com | Outbound HTTPS fetch; response is untrusted (public CSV from a third party) |
| csv rows → parquet store | Parsed rows land in a local file; malformed values could corrupt downstream computation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Tampering | CSV rows from cdn.cboe.com | mitigate | pd.to_numeric(..., errors="coerce") + dropna() on all numeric columns; malformed rows are silently dropped with a log line rather than persisted as NaN or string poison |
| T-15-02 | Denial of Service | Oversized response from CBOE | accept | VIX full history is ~350 KB; no streaming needed; timeout=30 caps wall time. Risk is negligible for a local research tool. |
| T-15-03 | Information Disclosure | TLS verification | accept | requests default verifies TLS (verify=True is the default); no secrets are in transit; endpoint is public read-only data |
| T-15-04 | Tampering | Parquet store on local disk | accept | Local filesystem; no multi-user access; read-only to CBOE. Idempotency guard prevents self-corruption on re-run. |
| T-15-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed this phase; all dependencies already in requirements.txt and audited in 15-RESEARCH.md Package Legitimacy Audit |
</threat_model>
