# Phase 16.5 Plan 02: Display Layer for OI Depth Expansion Summary

**One-liner:** gold triangle-up large-block annotation wired into the OI-by-strike chart, plus a collapsible "OI by Expiry" expander with Δ OI column in the Positioning tab — both display-only, consuming outputs from plan 01.

## What Was Built

**engine/gex/analytics.py** — `plot_oi_by_strike()` extended:
- Conditional block after vline annotations: if `is_top_decile` in `chain_df.columns` and any rows are True, adds a `go.Scatter` trace with `symbol="triangle-up"`, size=8, gold color `rgba(255,215,0,0.8)`, white outline, `name="large block (top 10%)"`, `showlegend=True`
- y-position uses `call_oi` if present, else `oi` — handles both chain_df shapes
- No-op when `is_top_decile` column absent — full backward compat

**app.py** — two additions:
- `from engine.data.oi_history import prior_oi_snapshot` added to imports (line 21)
- `with st.expander("OI by Expiry", expanded=False):` block added after the γ-flip expander, still inside the `for ticker in selected_all:` loop
  - Retrieves `expiry_oi_df = data.get("expiry_oi_df")` — shows unavailable caption if None/empty
  - Calls `prior_oi_snapshot(ticker, date.today())` to build `prior_oi_map` dict (str(expiry) → oi float)
  - Formats table: Expiry (strftime "%b %d"), DTE (int), OI/Calls/Puts (K-suffix), Δ OI (signed, K-suffix, "–" on cold start), P/C Ratio (2dp)
  - Column order: Expiry, DTE, OI, Δ OI, Calls, Puts, P/C Ratio
  - Renders via `st.dataframe(..., use_container_width=True, hide_index=True)`
