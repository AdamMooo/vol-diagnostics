## What Was Built

**engine/report/report.py** — `_oi_summary_table(expiry_oi_df)` added after `_ticker_card()`:
- Returns None on None or empty input (T-16.5-08 mitigate)
- `head(3)` of already-sorted-by-oi-desc DataFrame
- Columns: Expiry (strftime "%b %d"), OI (K suffix), Calls (K, call color), Puts (K, put color), P:C Ratio (2dp)
- Wraps in div with border-top RULE_COLOR, margin-top/bottom 12px, "OI BY EXPIRY" label
- Uses LABEL_GRAY, RULE_COLOR, _SANS, _MONO, config.PALETTE["call"/"put"]

**engine/report/report.py** — `build_email()` updated:
- New optional `oi_data: dict | None = None` parameter (backward-compat default)
- When provided: concatenates `_ticker_card(r)` + `_oi_summary_table(oi_data.get(r["ticker"]))` per result
- When None: identical behavior to before this change

**engine/run_daily.py** — two additions:
- `from engine.data.oi_history import save_oi_snapshot` import at top
- In per-ticker success block: `save_oi_snapshot(expiry_oi_df, ticker, today)` in non-blocking try/except after `save_surface_snapshot`
- `oi_data` dict built from all_data before `build_email` call and passed as kwarg
