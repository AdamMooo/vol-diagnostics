## What Was Built

**engine/data/oi_history.py** — new parquet store, exact mirror of surface_history.py:
- `save_oi_snapshot(expiry_oi_df, ticker, date)`: idempotent write, returns early on None/empty (T-16.5-02 mitigate), prints summary line
- `load_oi_snapshot(ticker, date)`: returns per-expiry rows without date/ticker columns; empty DataFrame on missing store or date
- `prior_oi_snapshot(ticker, before_date)`: most recent date strictly before before_date; empty DataFrame on cold start
- `list_oi_dates(ticker)`: newest-first sorted list; [] on missing store
- STORE_DIR: `out/oi_history/oi_{ticker}.parquet`

**engine/gex/exposure_engine.py** — `expiry_oi(df)` added after `strike_oi()`:
- pivot_table on expiry (same pattern as strike_oi on strike)
- DTE cap via `config.GEX_MAX_DTE` applied internally
- computes: dte (T_years×365 rounded 1dp), pct_of_total, put_call_ratio (clip denom 1e-6)
- sorted by oi descending
- returns empty DataFrame with correct columns when all options beyond DTE cap

**engine/compute.py** — three changes:
- `expiry_oi` added to import from engine.gex.exposure_engine
- `is_top_decile` boolean column computed on s_df after strike_oi merge (`oi_vals >= oi_vals.quantile(0.9)`, all-False when no OI)
- `expiry_oi_df = expiry_oi(gex_df)` computed and added as `"expiry_oi_df"` key in return dict
