# Sketch Manifest

## Design Direction
Personal market-health dashboard for a discretionary reader. The first question is always "what's the environment — should I be worried?" Not a PM income-sleeve tool anymore. Calm authority, not trading terminal. Think morning research note: bold read, supporting evidence, no noise.

## Reference Points
- Goldman Sachs Marquee morning brief (editorial + data)
- Notion-style minimal UI (large type, space to breathe)
- Bloomberg BRIEF (narrative-first, metrics as support)
