<objective>
Close the loop on ROADMAP Phase 20.5 success criterion #4 ("Suite stays green; visual result verified by sending a real test email ... not just unit tests"). This plan runs no code changes -- it runs the existing `run_daily.py --dry-run` path to produce a real HTML file from the now-remodeled `report.py`/`png_export.py`, and asks the user to visually confirm the result (and optionally trigger a real send) before the phase is considered done.

This plan is the human-in-the-loop check that closes that gap.
Output: A dry-run HTML file in `out/gex/`, PNG attachments at the new resolution, and explicit user sign-off (or a list of issues to route back into a follow-up plan).
</objective>
