  <behavior>

    _construct_grid_axes(surface_df) -> tuple[np.ndarray, np.ndarray]:
    - dte_max = min(surface_df["dte"].max(), config.SURFACE_DTE_MAX)
    - dte_grid = np.linspace(5.0, dte_max, config.SURFACE_GRID_DTE)
    - otm_grid = np.linspace(-config.SURFACE_PLOT_OTM_CLIP * 100.0, config.SURFACE_PLOT_OTM_CLIP * 100.0, config.SURFACE_GRID_LM)
    - Returns (dte_grid, otm_grid)
    - Grid axes are derived from today's surface so all baseline comparisons use the same shape

    compute_evolution_scalars(ticker, date, prior_date) -> dict | None:
    - Loads today's surface via load_surface_snapshot(ticker, date); if empty returns None
    - Loads prior surface via load_surface_snapshot(ticker, prior_date); if empty returns None
    - Constructs grid axes from today's surface_df via _construct_grid_axes
    - Calls rbf_grid and coverage_mask for today using today's spot and the shared grid axes
    - Calls rbf_grid and coverage_mask for prior_date using prior's spot and the SAME shared grid axes
    - Computes mask_intersection = mask_today & mask_prior (boolean AND; both must be True)
    - IV_diff = IV_today - IV_prior (raw diff, no masking yet)
    - IV_diff_masked = np.where(mask_intersection, IV_diff, np.nan)
    - level = np.nanmean(IV_diff_masked)
    - rms = np.sqrt(np.nanmean(IV_diff_masked ** 2))
    - skew_change: put_wing_idx = otm_grid < config.SURFACE_EVOLUTION_PUT_WING_CLIP; call_wing_idx = otm_grid > config.SURFACE_EVOLUTION_CALL_WING_CLIP; skew_change = np.nanmean(IV_diff_masked[put_wing_idx, :]) - np.nanmean(IV_diff_masked[call_wing_idx, :])
    - term_change: dte_front_idx = dte_grid <= config.SURFACE_EVOLUTION_DTE_FRONT_MAX; dte_back_idx = dte_grid >= config.SURFACE_EVOLUTION_DTE_BACK_MIN; atm_idx = np.abs(otm_grid) <= config.SURFACE_EVOLUTION_ATM_CLIP; front_atm = IV_diff_masked[np.ix_(atm_idx, dte_front_idx)]; back_atm = IV_diff_masked[np.ix_(atm_idx, dte_back_idx)]; term_change = np.nanmean(front_atm) - np.nanmean(back_atm)
    - coverage = float(np.sum(mask_intersection)) / mask_intersection.size
    - Returns dict with keys: level, rms, skew_change, term_change, coverage; all floats; never replaces NaN with 0

    NOTE — compute_evolution_scalars is POINT-TO-POINT (today vs single prior_date). update_evolution builds the rolling-mean baseline by loading N prior dates and stacking. See update_evolution behavior below.

    save_evolution_row(date, ticker, horizon, prior_date, level, rms, skew_change, term_change, coverage) -> None:
    - Builds row dict with all nine schema columns; date and prior_date are datetime.date objects
    - Read-filter-concat-write idempotency: if STORE exists, pd.read_parquet → coerce _FLOAT_COLS to float64 → drop rows where (date==row["date"]) & (ticker==ticker) & (horizon==horizon) → concat new row → write
    - If STORE does not exist: STORE.parent.mkdir(parents=True, exist_ok=True); write DataFrame([row])
    - Print: f"[surface_evolution] {ticker} {date} horizon={horizon}: level={level:.2f}pp rms={rms:.2f}pp saved"

    load_evolution(ticker, horizon=None, days=30) -> pd.DataFrame:
    - Mirrors gex/validation.py load_history pattern exactly, with optional horizon filter
    - Returns empty DataFrame if store does not exist or on exception (with print warning)

    update_evolution(ticker, date) -> None:
    - Iterates HORIZONS = (5, 10, 20)
    - For each horizon N: calls nth_trading_day_back(ticker, date, N); if None, skips (cold-start)
    - Loads today's surface once outside the horizon loop (reuse across horizons)
    - For the rolling-mean baseline: loads all N prior days' surfaces (nth_trading_day_back for N=1..N-1 does NOT apply — the baseline is the mean of the single prior_date snapshot for point-to-point; see NOTE above)
    - CLARIFICATION: EVOL-01 specifies the headline baseline as N-day rolling mean. For this engine: update_evolution for horizon N calls nth_trading_day_back(ticker, date, N) to get the single prior date that is N sessions back, then calls compute_evolution_scalars(ticker, date, prior_date) which diffs today vs that single session. The N-day rolling mean of the surface is the mean over the N sessions up to prior_date — i.e., load sessions at positions 1..N back and average them as the baseline. Implementation: load IV grids for all sessions from position 1 through N back (inclusive), stack them, nanmean → IV_baseline; intersect all N+1 masks (today + N prior); diff today vs IV_baseline.
    - REVISED update_evolution: for horizon N, resolve dates at positions 1, 2, ..., N back (not just position N); load all N grids; stack → nanmean → IV_baseline_mean; AND all N+1 masks (today + each prior day); compute scalars on IV_diff_masked; label prior_date as nth_trading_day_back(ticker, date, N) (the furthest day in the window)
    - Call save_evolution_row with horizon=N and prior_date=nth_trading_day_back(ticker, date, N)
    - If any individual prior day's surface is empty, skip it in the stack (do not skip the whole horizon unless stack is empty)
