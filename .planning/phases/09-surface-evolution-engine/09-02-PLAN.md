    _construct_grid_axes(surface_df) -> tuple[np.ndarray, np.ndarray]:
    - dte_max = min(surface_df["dte"].max(), config.SURFACE_DTE_MAX)
    - dte_grid = np.linspace(5.0, dte_max, config.SURFACE_GRID_DTE)
    - otm_grid = np.linspace(-config.SURFACE_PLOT_OTM_CLIP * 100.0, config.SURFACE_PLOT_OTM_CLIP * 100.0, config.SURFACE_GRID_LM)
    - Returns (dte_grid, otm_grid)
    - Called exactly once per update_evolution invocation, from today's surface_df only; the returned axes are passed unchanged to every rbf_grid and coverage_mask call for today AND all prior dates

    compute_evolution_scalars(IV_diff_masked, otm_grid, dte_grid) -> dict:
    - Pure function — receives the already-masked diff array and the shared grid axes; performs no I/O, no masking, no snapshot loading
    - Signature: (IV_diff_masked: np.ndarray, otm_grid: np.ndarray, dte_grid: np.ndarray) -> dict
    - level = np.nanmean(IV_diff_masked)
    - rms = np.sqrt(np.nanmean(IV_diff_masked ** 2))
    - skew_change: put_wing_idx = otm_grid < config.SURFACE_EVOLUTION_PUT_WING_CLIP; call_wing_idx = otm_grid > config.SURFACE_EVOLUTION_CALL_WING_CLIP; skew_change = np.nanmean(IV_diff_masked[put_wing_idx, :]) - np.nanmean(IV_diff_masked[call_wing_idx, :])
    - term_change: dte_front_idx = dte_grid <= config.SURFACE_EVOLUTION_DTE_FRONT_MAX; dte_back_idx = dte_grid >= config.SURFACE_EVOLUTION_DTE_BACK_MIN; atm_idx = np.abs(otm_grid) <= config.SURFACE_EVOLUTION_ATM_CLIP; front_atm = IV_diff_masked[np.ix_(atm_idx, dte_front_idx)]; back_atm = IV_diff_masked[np.ix_(atm_idx, dte_back_idx)]; term_change = np.nanmean(front_atm) - np.nanmean(back_atm)
    - coverage = float(np.sum(~np.isnan(IV_diff_masked))) / IV_diff_masked.size
    - Returns dict with keys: level, rms, skew_change, term_change, coverage; all floats; never replaces NaN with 0

    update_evolution(ticker, date) -> None:
    IMPLEMENTS THE CANONICAL 8-STEP ROLLING-MEAN ALGORITHM (from RESEARCH.md Q2):

    Step 1. Load today's surface: surface_today, spot_today = load_surface_snapshot(ticker, date). If surface_today is empty or spot_today is None, return early.
    Step 2. Construct grid axes ONCE from today's surface: dte_grid, otm_grid = _construct_grid_axes(surface_today). These axes are used for EVERY rbf_grid and coverage_mask call in this invocation — for today and ALL prior dates.
    Step 3. Compute today's grid + mask using the shared axes: IV_today = rbf_grid(surface_today, spot_today, dte_grid, otm_grid, dte_floor=5); mask_today = coverage_mask(surface_today, spot_today, dte_grid, otm_grid, dte_floor=5).

    For each horizon N in HORIZONS (5, 10, 20):
      Step 4. Resolve the N prior session dates at positions 1, 2, ..., N back via nth_trading_day_back. First verify the horizon is satisfiable: prior_date_N = nth_trading_day_back(ticker, date, N). If prior_date_N is None, skip this horizon entirely (cold-start) — write no row.
              Then resolve all N prior dates: prior_dates = [nth_trading_day_back(ticker, date, k) for k in range(1, N+1)], filtering out any None entries.
      Step 5. For each prior date in prior_dates: load its snapshot (surface_prior, spot_prior) using THAT day's own stored spot. Compute IV_prior = rbf_grid(surface_prior, spot_prior, dte_grid, otm_grid, dte_floor=5) and mask_prior = coverage_mask(surface_prior, spot_prior, dte_grid, otm_grid, dte_floor=5) — using the SAME shared grid axes from Step 2. Collect valid grids and masks (skip any date where surface is empty or spot is None, but do not skip the whole horizon unless the resulting stack is empty).
      Step 6. Stack the collected prior IV grids: IV_baseline_stack = np.stack(IV_grids, axis=0); IV_baseline_mean = np.nanmean(IV_baseline_stack, axis=0). If IV_grids is empty, skip this horizon.
      Step 7. Compute mask intersection: mask_intersection = mask_today; then AND each collected mask_prior into it sequentially (mask_intersection &= mask_prior for each prior mask). This is the boolean AND of all N+1 masks (today + each valid prior day).
      Step 8. IV_diff = IV_today - IV_baseline_mean; IV_diff_masked = np.where(mask_intersection, IV_diff, np.nan). Call compute_evolution_scalars(IV_diff_masked, otm_grid, dte_grid) to get the four scalars. prior_date label = nth_trading_day_back(ticker, date, N) (the furthest day in the window). Call save_evolution_row with horizon=N and the computed scalars.

    ACCEPTANCE CRITERIA (encoded, verifiable):
    - _construct_grid_axes is called exactly once per update_evolution call; dte_grid and otm_grid are local variables passed by reference to every rbf_grid and coverage_mask call — they are NEVER recomputed inside the horizon loop
    - All grids stacked in IV_baseline_stack have shape (config.SURFACE_GRID_LM, config.SURFACE_GRID_DTE) = (30, 40); if a prior day's surface yields a different shape, this is a bug — do not proceed
    - mask_intersection is always the AND of mask_today AND all N prior day masks; it is computed BEFORE IV_diff_masked and passed to compute_evolution_scalars which does NO additional masking

    save_evolution_row(date, ticker, horizon, prior_date, level, rms, skew_change, term_change, coverage) -> None:
    - Builds row dict with all nine schema columns; date and prior_date are datetime.date objects
    - Read-filter-concat-write idempotency: if STORE exists, pd.read_parquet → coerce _FLOAT_COLS to float64 → drop rows where (date==row["date"]) & (ticker==ticker) & (horizon==horizon) → concat new row → write
    - If STORE does not exist: STORE.parent.mkdir(parents=True, exist_ok=True); write DataFrame([row])
    - Print: f"[surface_evolution] {ticker} {date} horizon={horizon}: level={level:.2f}pp rms={rms:.2f}pp saved"

    - Mirrors gex/validation.py load_history pattern exactly, with optional horizon filter
    - Returns empty DataFrame if store does not exist or on exception (with print warning)
