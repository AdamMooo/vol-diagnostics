## Key Findings

1. The phase is mostly **hardening and reordering**, not new analytics: compact scorecard, trust framing, table-first OI, methods depth controls, and clearer evolution summary.
2. OI history is already persisted and available; use it directly in UI context columns (`5d Avg Share`, `vs 5d Avg`) rather than adding new stores.
3. Current positioning flow remains broad-tenor by default; phase should make **14 DTE the primary dealer-impact lens** while retaining broader context as secondary.
4. Methods/assumptions is currently too long for default PM flow; implement quick-first + deep-expand pattern.
5. Evolution already has scalar inputs (`level`, `rms`, `skew_change`, `term_change`) to produce a plain-English “what changed most today” summary row.
6. Canonical seams must be preserved: compute in engine, rendering via shared card/report patterns (no renderer-local metric recomputation).
