      - `gex_snapshots`: target **750 sessions** per ticker. Schema: date, ticker, spot, dte, strike, moneyness, log_moneyness, iv_pct.
      - `vol_index`: target reuses `config.VRP_DEEP_LOOKBACK_SESSIONS = 2500` sessions. Rationale: this is CBOE-published external history (VIX to 1990, VXN/RVX to 2009) already exceeding any plausible modeling requirement — no new number needed; state explicitly that this series is "already deep enough" and the constant is restated here only for traceability with the code. Schema: symbol, date, open, high, low, close.
      - `oi_history`: target **251 sessions** per ticker, same reasoning as surface_history (per-day cross-sectional aggregate, not a return series — one seasonal cycle is the bar, not a GARCH minimum). Schema: date, ticker, expiry, dte, call_oi, put_oi, oi, pct_of_total, put_call_ratio.
