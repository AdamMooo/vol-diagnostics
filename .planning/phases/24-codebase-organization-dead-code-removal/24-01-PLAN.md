    Run two sweeps from the repo root:
    - `python -m vulture engine app.py --min-confidence 80` (unused functions, classes, variables, attributes)
    - `python -m pyflakes engine app.py` (unused imports, redefinitions, undefined names)

    Triage EVERY finding into one of two buckets, and record the disposition in the SUMMARY:
    - REMOVE — genuinely unreachable/unused. Delete with the smallest possible diff. Do NOT restructure modules, rename, or reorganize the `engine/` layout (per project small-diffs rule) — delete the dead symbol/import only.
    - KEEP (triaged) — a false positive. Known false-positive categories to protect: CLI `__main__` entry points (`run_daily`, `run_gex`, `surface_sweep`, `calibration`, `health_check`, `backup_to_oci`, `restore_from_oci`); Streamlit dynamic refs and `@st.fragment` callbacks in app.py; plotly.js callback names; `__all__` exports; pytest fixtures and tombstone/guard assertions (e.g. `assertNotIn` guards in test files); public API surfaces re-exported via `__init__.py`. For each KEEP, write a one-line rationale in the SUMMARY. Add an inline `# vulture: ignore` only where the finding will otherwise recur on future ad-hoc sweeps AND the name is truly dynamic — prefer the SUMMARY triage note over littering source.

    Scope guard: the sweep target is `engine/` (source) + `app.py` only, per ROADMAP criterion 1. Do NOT expand into `runners/gex_daily.ps1` (a known-stale non-Python runner, tracked separately in STATE) or `out/` or `.planning/`. If the sweep surfaces a stale reference outside this scope, note it in the SUMMARY as out-of-scope — do not act on it here.

    Do NOT delete any symbol referenced only by a test unless the test itself is a tombstone guard; a symbol under live test is by definition not dead.
  </action>
