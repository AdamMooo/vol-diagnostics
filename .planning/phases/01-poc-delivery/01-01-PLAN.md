| T-01-02 | Information Disclosure (creds in error message) | BloombergCon exception handler | mitigate | Catch exception, print generic message ("BloombergCon failed: {ticker}/{field}"), no stack trace of emds_client auth details |
| T-01-03 | Denial of Service (stale/missing cache) | Cache fallback path | accept | No critical service; POC runs manually; missing data returns empty DataFrame, math layer handles gracefully with dropna() |
| T-01-04 | Denial of Service (emds_client down) | USE_BLOOMBERG path | accept | Fallback to FreeCon automatic if BLOOMBERG_AVAILABLE=False; user verifies on Cron2 before delivery |

</threat_model>
