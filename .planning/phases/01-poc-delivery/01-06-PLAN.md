**Section C: Sleeve Returns by Signal Quartile (lines 434–458, adapt strongly):**
```markdown
### Section C — Sleeve Returns by Signal Quartile

**What it shows:** Historical mean monthly returns for each sleeve, broken down by the quartile of a signal **at roll open**.

**Example:** "When VRP was in Q4 (top 25%), covered call returned +1.5% on average in the full backtest period."

**How to read it:**
1. Find today's signal in the "today: X → Q?" row
2. Look at that quartile's returns for each sleeve in the historical backtest (1y lookback)
3. Check if the Q4-vs-Q1 difference is significant (marked with ** if Holm-survives, or (raw) if raw p<0.05)

**What Holm-Bonferroni correction means:**
Because we run many tests (underlyings × signals × sleeves), raw p-values must be adjusted to control family-wise error rate (FWE α=0.05). This prevents false positives from multiple testing.

- `n tests`: Total number of (underlying × signal × sleeve) comparisons we ran
- `raw p<0.05`: How many would pass if we ignored multiple comparisons
- `Holm-survives`: How many still look significant after family-wise adjustment

**Key insight — This is a feature, not a bug:** If 0 tests survive Holm (which is typical), the apparent quartile differences are likely false positives from multiple testing. This means:
- The framework **does not claim** that today's signal predicts next month's sleeve return
- The rigor is the credibility centerpiece — it tells you what you cannot defensibly claim
- Test results inform framework design but are not marketed as a system

**Limitations:**
- In-sample: these are historical means, not predictions
- Assumes future signal ↔ return relationship is stable (testable with walk-forward; deferred to Phase 6)
- Lagged signals at roll open (realistic for trading, causality-safe, but not real-time)

**Built with:** Welch's t-test for Q4-vs-Q1 contrast; Holm-Bonferroni FWE correction (α=0.05); stationary block bootstrap for Sharpe CI (block ≈ 6 months to span autocorrelation).

---
```

```markdown
### Section D — Past Periods That Looked Like Now

**What it shows:** K=12 historical periods where the signal vector (vrp, term, skew, trend, dd, fragility) was closest to today, and what the environment realized in the following 1/3/6 months.

**How to read it:**
1. "Today's vector" row: today's percentile ranks on key signals
2. "Closest analogs": K=12 dates where history looked most like today (Euclidean distance in signal space)
3. For each match: "Forward-realized environment" — what happened to signals (vrp, skew, term, dd) in the following 1, 3, and 6 months

**Example:** "In the past, when vrp was 0.6 (high premium), term was 0.3 (flat), skew was 0.8 (steep put discount)..., the realized environment shifted to: vrp→0.45, term→0.4, skew→0.6 within the following month."

**Why this framing — Pure historical co-movement:** No forecast claim. You use this to think: "If the environment typically flows toward [X] after conditions like today, what sleeves do I want to be long?"

**What it is NOT:**
- NOT a forecast of where signals will go
- NOT a sleeve return prediction
- NOT a recommendation for which sleeve to pick
- NOT claiming: "This pattern always leads to X outcome"

**Limitations:**
- K=12 is arbitrary (POC choice); sensitivity to K untested
- Assumes past co-movements reflect future (testable; deferred to Phase 6)
- Only 5y of history; pre-2020 market dynamics may not apply to current regime
- Does not account for macro catalysts (Fed policy, earnings, geopolitical shocks)

**Built with:** K-nearest neighbors in signal space (Euclidean norm over six features); forward-realized signals at T+1m/3m/6m trading days from match date.

---
```
