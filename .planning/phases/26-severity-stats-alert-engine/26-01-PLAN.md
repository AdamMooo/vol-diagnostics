Implement `engine/monitor/ranker.py` with two pure functions (no I/O, mirrors vrp_history.py's percentile pattern exactly — reuse `percentileofscore(..., kind="rank")`):

`compute_level_ranks(history: pd.Series, today_value: float | None, deep_lookback: int | None = None, oneyr_lookback: int = config.MONITOR_ONEYR_LOOKBACK_SESSIONS) -> dict` returning `{"level_rank_deep": int|None, "n_deep": int, "level_rank_1yr": int|None, "n_1yr": int}`. `deep_lookback=None` uses full available history (mirrors vrp_percentile's default); `oneyr_lookback` always slices the tail 252 (config.MONITOR_ONEYR_LOOKBACK_SESSIONS) rows regardless of deep window size — the two lookbacks are independent, not nested assumptions.

`compute_change_rank(history: pd.Series, today_value: float | None = None, k: int = config.MONITOR_CHANGE_K_SESSIONS, lookback: int | None = None) -> dict` returning `{"change_rank": int|None, "change_n": int}`. Computes `abs_changes = history.diff(k).abs().dropna()`; today's change is `abs_changes.iloc[-1]` if `today_value` is None (history already includes today as its last point), else compute directly from `today_value` and `history` per the same k-day-back convention. Rank via `percentileofscore(window.to_numpy(), todays_abs_change, kind="rank")`.

Both functions: never raise (broad try/except returning none-dicts on any failure, mirroring vrp_history.py's `none_dict` pattern); explicit `.dropna()` before any numpy conversion.
