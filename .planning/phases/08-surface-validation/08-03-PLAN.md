<design_notes>
- surface_diagnostics HOME = exposure_engine.py (confirmed against ARCHITECTURE-v3.3 §1: sits beside
  compute_surface_slopes, pure DataFrame-in/dict-out, no I/O). It imports rbf_grid/coverage_mask
  from gex.analytics (deferred import inside the function to match the convention and avoid a
  circular import, since analytics already imports from report; verify import direction at build).
- Leave-one-EXPIRY-out CV (NOT leave-one-point-out): adjacent strikes correlate and flatter the
  error (PITFALLS-v3.3 #4). Hand-rolled refit loop on scipy RBFInterpolator. scikit-learn REJECTED.
- Coherence checks are flag-only: calendar total-variance (IV²·T) non-decreasing in T along each
  OTM slice; butterfly convexity (second difference of IV across strikes within an expiry ≥ 0,
  i.e. no negative implied density). Count violations; PASS = zero violations. Log violation
  locations to stdout. Never modify the surface.
</design_notes>

  <behavior>
    - surface_diagnostics(surface_df, spot) -> dict with keys exactly:
        coverage_pct (float), fit_rmse (float, pp), max_resid (float, pp),
        cv_rmse (float, pp — leave-one-expiry-out), coherence_calendar (bool PASS),
        coherence_butterfly (bool PASS), coherence_violations (int)
    - fit_rmse: RBF evaluated AT the real quote locations vs their actual iv_pct; RMSE in pp
    - max_resid: max abs(fitted - actual) in pp
    - cv_rmse: for each distinct expiry (dte value), drop that expiry's quotes, refit RBF on the
      rest, predict the held-out expiry's strikes, accumulate residuals; RMSE across all held-out
      points. Requires ≥2 expiries with quotes; else cv_rmse = nan.
    - coverage_pct: 100 × coverage_mask(...).mean() on the standard grid
    - coherence_calendar: total variance IV²·T non-decreasing in T along each %OTM slice (use the
      raw quotes grouped to a few moneyness buckets, or evaluate the fitted grid column-wise);
      PASS = no decreasing step beyond a small tolerance
    - coherence_butterfly: within each expiry, second difference of iv across sorted strikes ≥
      -tol (no negative implied density / no ringing); PASS = no violation
    - coherence_violations: total count of (calendar + butterfly) violations
    - On <6 in-band points → return a dict with nan floats and coherence True/0 (degrade, never raise)
    - On surface_df empty/None → same nan-degraded dict
  </behavior>
  <action>
    Add `def surface_diagnostics(surface_df, spot) -> dict` to gex/exposure_engine.py, beside the
    other pure surface metrics. Build the standard grid the same way plot_vol_surface does
    (dte floor=5, dte_max via config, otm clip ±SURFACE_PLOT_OTM_CLIP×100, SURFACE_GRID_DTE/LM points).

    1. In-band filter the quotes (|%OTM| ≤ clip, dte ≥ 5). If <6 → return nan-degraded dict.
    2. fit_rmse / max_resid: fit one RBF on all in-band quotes (reuse the rbf_grid normalization
       inline, or evaluate RBFInterpolator directly at the quote points). residual = fitted − actual
       at each quote. fit_rmse = sqrt(mean(resid²)); max_resid = max(abs(resid)). Units: pp.
    3. cv_rmse (leave-one-EXPIRY-out): for each unique dte, mask it out, refit RBFInterpolator
       (kernel="thin_plate_spline", smoothing=config.SURFACE_SMOOTHING, same pts_std normalization)
       on the remaining quotes, predict the held-out expiry's (dte,%OTM) points, collect residuals.
       cv_rmse = sqrt(mean(all held-out resid²)). If <2 expiries → nan.
    4. coverage_pct = 100 * float(coverage_mask(surface_df, spot, dte_grid, otm_grid).mean())
    5. coherence_calendar: for a handful of fixed %OTM levels (e.g. -10,-5,0,+5,+10), read the
       fitted IV up the DTE axis, compute total variance w = (IV/100)²·(DTE/365), flag any
       w[i+1] < w[i] - 1e-6. coherence_calendar = (no flags). Print each violation location.
    6. coherence_butterfly: group raw quotes by expiry; within each expiry with ≥3 strikes, sort by
       strike, compute discrete second difference of iv_pct; flag any < -tol (tol e.g. 0.5pp to
       tolerate quote noise). coherence_butterfly = (no flags). Print violation (expiry, strike).
    7. coherence_violations = total flags. PASS booleans logged:
       `print(f"[coherence] calendar={'PASS' if ... else 'FAIL'} butterfly=... violations=N")`
       — note: ticker isn't passed; keep the signature (surface_df, spot) and log generic;
       compute_ticker can re-log with ticker. ALL log language about surface consistency, never
       trading opportunity.

    Create gex/tests/test_surface_diagnostics.py:

    - inject a calendar violation (a long-DTE slice with LOWER total variance than a short one) →
      coherence_calendar False, coherence_violations ≥ 1.
    - inject a butterfly violation (a concave dip in one expiry's smile) → coherence_butterfly False.
    - <6 points → all-nan floats, no raise.
    - leave-one-expiry-out: cv_rmse is nan with a single expiry, a finite float with ≥2.
