    Sweep 1 — smoothing (fit accuracy vs over-flattening):
      - candidates e.g. [0.0, 0.5, 1.0, 1.5, 2.0, 3.0, 5.0]
      - for each, compute fit_rmse + max_resid (pp) by fitting RBF at that smoothing and evaluating

        a helper or recompute). Lower RMSE = better fit, but flag when smoothing is so low the smile
        develops ringing (you may also report cv_rmse via leave-one-expiry-out for robustness).
      - print a table: smoothing | fit_rmse | max_resid | cv_rmse

    Sweep 2 — COVERAGE_KNN_K (coverage vs hole-count):
      - candidates e.g. [1.0, 1.5, 2.0, 2.5, 3.0]
      - for each, compute coverage_pct = 100*coverage_mask(..., k=cand).mean() and hole_count =
        number of False cells on the standard grid.
      - print a table: k | coverage_pct | hole_count

    Print a closing one-line note stating the currently-configured values
    (config.SURFACE_SMOOTHING, config.COVERAGE_KNN_K) and that they are kept unless the tables
    clearly argue otherwise. Do NOT auto-edit config from the script — it is a documentation/proof
    tool, the human reads the table and decides.

    Exit 0 on success. If no data at all (empty store AND live fetch fails), print a clear message
    and exit 0 (not a crash) so the script is safe to run any time.

    Create gex/tests/test_surface_sweep.py:
    - import the sweep's core functions (factor the two sweeps into testable functions returning
      lists/DataFrames, with the __main__ block just printing them).
    - on a synthetic surface_df, assert the smoothing sweep returns one row per candidate with
      finite fit_rmse, and that higher smoothing yields ≥ the fit_rmse of lower smoothing on a noisy
      chain (monotone-ish — or at least all finite and ordered candidates present).
    - assert the k sweep returns one row per candidate and coverage_pct is non-decreasing in k
      (larger radius → more cells supported).
