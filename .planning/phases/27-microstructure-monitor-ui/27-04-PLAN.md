<objective>
Reshape the daily email from an always-present descriptive report into an event-shaped alert digest: body = band entries + escalations only (one row each, with Δ-vs-yesterday context), near-empty "nothing unusual" on quiet days. Replace the methodology caveat banner + glossary + deep-methodology footer with a single Methodology link; remove the OI-by-expiry table and key-levels block from the email (dashboard-only now).

Purpose: The monitor's default output is silence — the email's job is to fire loudly and credibly only when structure hits an extreme (locked design D3). This is a genuine reframe of the email body, not a scope reduction: the removed descriptive content moves to the dashboard (Plans 02/03).
Output: Event-shaped `build_email` in `report.py`, wired in `run_daily.py`, with a config link constant and tests using a synthetic alert fixture (real alerts have never fired — cold start).
</objective>
