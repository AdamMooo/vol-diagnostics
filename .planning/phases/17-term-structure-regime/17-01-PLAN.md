## Tasks

### Task 1: Engine — `compute_term_ratios()` + compute_ticker wiring

**File:** `engine/vol/vol_metrics.py` (new function), `engine/compute.py` (wiring)

Add `compute_term_ratios(ticker: str) -> dict` to `vol_metrics.py`:
- Maps ticker → vol-index symbols: SPY → (VIX9D, VIX, VIX3M); QQQ/IWM → None
- Loads latest close from `load_vol_index` for each required symbol
- Returns `{"vix9d_vix": float|None, "vix_vix3m": float|None}` — None on missing data
- For QQQ/IWM returns `{"vix9d_vix": None, "vix_vix3m": None}` (no fabrication)

Wire into `compute_ticker()`:
- Call `compute_term_ratios(ticker)` and merge keys into `summary`
- Keys: `term_ratio_9d_30d`, `term_ratio_30d_3m`

### Task 2: Card model — VIX Term field
