    Create gex/png_export.py as a new module. Module docstring: "PNG export from Plotly
    figures via kaleido. Non-blocking — returns None on any failure."

    Imports: `from __future__ import annotations`, `import datetime`, `from pathlib import Path`,
    `import plotly.graph_objects as go`, `from gex import config`.

    Function signature:
      def export_png(fig: go.Figure, ticker: str, surface_type: str,
                     date: datetime.date, out_dir: Path | None = None) -> Path | None

    Implementation:
    1. Resolve out_dir: `out_dir = out_dir or (Path(__file__).resolve().parents[1] / "out")`
    2. `out_dir.mkdir(parents=True, exist_ok=True)`
    3. Apply pinned camera: `fig.update_layout(scene=dict(camera=dict(eye=config.KALEIDO_CAMERA_EYE)))`
    4. Build filename: `f"{ticker.lower()}_{surface_type}_{date.strftime('%Y%m%d')}.png"`
    5. Call `fig.write_image(str(png_path), format="png")` inside try/except Exception as exc
    6. On failure: `print(f"[WARN] PNG export failed ({surface_type}/{ticker}): {exc}")` then `return None`
    7. On success: `return png_path`

    Create gex/tests/test_png_export.py with the six behavior tests above using
    unittest.mock.patch to mock fig.write_image and fig.update_layout. Use
    `tmp_path` pytest fixture for out_dir so no real files are created.
  </action>
